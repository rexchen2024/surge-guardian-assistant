# Code Of Conduct

This project uses a simple rule: be clear, respectful, and useful.

## Expected Behavior

- Stay focused on the technical problem.
- Assume private network data is sensitive.
- Avoid posting secrets, logs, profiles, subscription URLs, node credentials, real domains, or real IPs.
- Give enough detail for others to reproduce the issue.
- Disagree with ideas without attacking people.

## Unacceptable Behavior

- Harassment or personal attacks.
- Publishing another person's private data.
- Posting credentials or private infrastructure details.
- Repeatedly derailing technical discussions.

## Reporting

For normal project issues, use GitHub issues.

For sensitive security problems, follow [SECURITY.md](SECURITY.md).
